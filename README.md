# ZIC.com.ve

Sitio corporativo de **Zulia Industrial Constructions, C.A.** — empresa venezolana de construcción industrial pesada desde 1973.

## Stack
- HTML single-file + Tailwind CDN
- IBM Plex Sans/Mono + Russo One
- IntersectionObserver para reveals/counters
- Modo claro/oscuro con persistencia (localStorage)

## Local
```bash
python3 -m http.server 8000
```

## Deploy
GitHub Pages → branch `main` → root. Custom domain: `zic.com.ve` (CNAME).

## Versión
**ZIC v4.7**
